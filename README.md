# Técnico Pro
App Android para técnico independiente: mantenimientos, licencias, alertas de vencimiento, WhatsApp y resumen financiero.

## Obtener el APK
1. Ve a la pestaña **Actions** del repositorio.
2. Abre la última ejecución de "Compilar APK" (o pulsa *Run workflow*).
3. Al terminar (≈10-15 min), descarga el artefacto **tecnico-pro-apk** (ZIP con el .apk).
4. Pásalo al teléfono e instálalo (permitir "orígenes desconocidos").
